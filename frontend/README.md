# Frontend — Angular (Stage 7)

This directory is intentionally empty until Stage 7.

The Angular workspace will be generated locally with:

    npm install -g @angular/cli
    ng new tea-ui --directory . --style=scss --routing

Reasons we scaffold it later, not now:
1. Stages 1–6 are backend-only; an unused node_modules slows everyone down.
2. Angular version is pinned right before the event to match whatever
   JiVS reference materials specify (v20 was required in 2025).
